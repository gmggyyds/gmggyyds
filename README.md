## 我是谁

<img align="right" width="150" src="./mascot.png" alt="Sam">

孙翔（Sam），做亚马逊 11 年。

大三在美国开始卖货，回国进了深圳前海浩方。先做蓝牙音箱做到亚马逊品类第二，又把音频线做到类目第一——**验证了同一套打法能跨品类复制**。后来在跨境社群优联荟带亚马逊板块、当高阶训练营船长，三年教了近万名跨境创业者，把手感写成了 22 万字的训练营笔记。

2021 年把教给别人的东西用回自己身上，创办哈库拉玛塔达，做自有品牌。现在的组织形态是**人 + AI Agent 混编**：面料研发到消费者全链路自持，一个品牌对应一种材料、一类人群。

2026 年入选福布斯中国新生代跨境电商 30 人。

这里放的是我在这条路上真正每天在用的工具，**不是 demo**。

## 我信什么

**先定生意，再定 Agent。** 大部分人反过来——先挑工具，再想拿它干嘛，然后收藏夹里躺着三百个再也不会打开的东西。

**AI 越强，基本功越值钱。** 它替不掉的是业务判断和审美——你判断错的方向，它只会让你更快地错下去。

**人的判断力才是生产力。** 所以我做的每一个东西，最后都指向同一件事：把你的判断喂给它，而不是拿它的判断替代你的。

**装了不用，收藏不看，那是吸星大法。**
